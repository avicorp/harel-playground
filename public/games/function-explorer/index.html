🔵 הפונקציה f(x)

f(x) = 1·x + 0
m 1
b 0

m משנה את התלילות (השיפוע) ו‑b מזיז את הגרף למעלה ולמטה.

🟡 הרכבה g(f(x))

g(f(x)) = 1·f(x) + 0
m 1
b 0

g מקבלת את התוצאה של f ומפעילה עליה פעולה נוספת. בחרו f⁻¹ ההופכית כדי לבטל את f.

הדליקו כדי לשרשר פונקציה שנייה על התוצאה של f.

🟣 הפונקציה ההופכית

f⁻¹(x) = (x − 0) / 1

ההופכית היא המכונה ההפוכה: היא מקבלת את f(x) ומחזירה את x. בגרף היא שיקוף של f בקו המקווקו y = x.

❓ מה זה בכלל פונקציה?

פונקציה היא מכונה: מכניסים לה מספר x, היא עושה עליו פעולה, ויוצא מספר אחר — f(x). כל x מקבל בדיוק תשובה אחת.

הגרף

כל נקודה בגרף אומרת: "כשהכנסתי x, יצא f(x)". הצירים ממשיכים גם למספרים שליליים — שמאלה ולמטה מהאפס.

m ו‑b בפונקציה ליניארית

  • m — השיפוע. גדול = עלייה תלולה, שלילי = הקו יורד, אפס = קו ישר ושטוח.
  • b — הגובה שבו הגרף חוצה את ציר ה‑y (כי כאשר x = 0 מקבלים f(0) = b).

שלוש משפחות

  • ליניארית m·x + b — קו ישר.
  • ריבועית m·x² + b — פרבולה, "חיוך" או "עצוב" לפי הסימן של m.
  • מעריכית m·2^x + b — צומחת מהר מאוד: כל צעד ימינה מכפיל את התוצאה.

הרכבה g(f(x))

שתי מכונות בשרשרת: מה שיוצא מ‑f נכנס ל‑g. קודם מחשבים את f(x), ואת התוצאה מכניסים ל‑g.

הפונקציה ההופכית

ההופכית f⁻¹ מבטלת את מה ש‑f עשתה: f⁻¹(f(x)) = x. אם f מכפילה ב‑2 ומוסיפה 3, ההופכית מחסירה 3 ומחלקת ב‑2 — ומקבלים בחזרה בדיוק את המספר שהתחלנו איתו. לכן כשבוחרים ב‑g את ההופכית, הגרף של ההרכבה הופך לקו y = x.
